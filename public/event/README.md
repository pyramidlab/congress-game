# AFCF Ekiti Area · Student Congress 1.0

Event artwork supplied by the organizer. The site is dedicated to this Congress.

- `afcf-logo.webp`: web delivery copy of `358876-removebg-preview.png`, 144 × 144, 5,282 bytes. The blue logo is displayed on a white badge for legibility.
- `congress-flier.webp`: web delivery copy of `IG AFCF POSTS_20261002_191911_0000.png`, 900 × 1125, 75,224 bytes. The supplied artwork, wording and layout are retained.

The flier loads lazily on the welcome page. Player, host and projector screens use only the small logo. No external image or font service is needed.

Event identity and details live in `src/lib/event.ts`. Dates are taken directly from the supplied flier; the site does not display a countdown or an upcoming-event claim.
